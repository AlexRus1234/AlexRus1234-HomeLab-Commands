Ниже представлено подробное описание каждого основного блока и параметров в предоставленном конфигурационном файле SFTPGo:

**Блок `"common"` (Общие настройки сервера):**

* 
`idle_timeout`: Время простоя (в минутах), после которого неактивный клиент будет принудительно отключен сервером.


* 
`upload_mode`, `setstat_mode`, `rename_mode`: Эти параметры определяют поведение файловой системы при загрузке файлов, изменении их атрибутов и переименовании (например, использование атомарной загрузки).


* 
`actions` и хуки (`startup_hook`, `post_connect_hook` и др.): Позволяют задать пути к внешним скриптам или HTTP-эндпоинтам, которые будут вызываться сервером при определенных событиях, таких как старт приложения или подключение пользователя.


* 
`proxy_protocol`, `proxy_allowed`: Параметры для настройки поддержки PROXY-протокола, что необходимо при работе сервера за балансировщиками нагрузки.


* 
`max_total_connections`, `max_per_host_connections`: Устанавливают глобальный лимит на общее число подключений к серверу и лимит одновременных подключений с одного IP-адреса.


* 
`defender`: Встроенная система защиты от брутфорс-атак. Она позволяет автоматически блокировать IP-адреса на определенное время (`ban_time`), если пользователь превышает допустимый порог нарушений (`threshold`). Нарушения оцениваются в баллах, например, за неверный пароль начисляется `score_invalid`, а за превышение лимита подключений — `score_limit_exceeded`.


* 
`rate_limiters`: Позволяет ограничить частоту запросов для различных протоколов (SSH, FTP, HTTP) для защиты от перегрузок.


* 
`event_manager`: Настройки внутреннего менеджера событий для автоматизации задач на сервере.



**Блок `"acme"` (Интеграция с Let's Encrypt / ACME):**

* 
`domains`, `email`: Список доменов, для которых необходимо автоматически получать TLS-сертификаты, и контактный email администратора.


* 
`certs_path`, `ca_endpoint`: Директория для сохранения готовых сертификатов и URL-адрес API удостоверяющего центра.


* 
`http01_challenge`, `tls_alpn01_challenge`: Настройки портов, используемых для прохождения автоматической проверки владения доменом.



**Блок `"sftpd"` (Настройки службы SFTP):**

* 
`bindings`: Массив привязок, где указывается рабочий порт (по умолчанию `2022`) и IP-адрес для прослушивания входящих SFTP-подключений.


* 
`max_auth_tries`: Максимально допустимое количество неудачных попыток авторизации в рамках одной сессии.


* 
`host_keys`, `trusted_user_ca_keys`: Указывают пути к ключам хоста самого сервера и ключам удостоверяющих центров для доверенной авторизации.


* 
`enabled_ssh_commands`: Список консольных команд, выполнение которых разрешено по протоколу SSH (например, утилиты `md5sum`, `scp`, `cd`).


* 
`keyboard_interactive_authentication`, `password_authentication`: Включают или отключают методы авторизации по интерактивному вводу и классическому паролю.



**Блок `"ftpd"` (Настройки службы FTP/FTPS):**

* 
`bindings`: Определяет порт (значение `0` означает, что служба FTP отключена), IP-адрес и настройки TLS-шифрования для FTPS.


* 
`passive_port_range`: Диапазон портов (например, `50000` - `50100`), который сервер будет использовать для передачи данных в пассивном режиме FTP.


* 
`disable_active_mode`: Позволяет полностью запретить использование небезопасного активного режима FTP.


* 
`certificate_file`, `certificate_key_file`: Пути к SSL/TLS сертификатам, необходимым для работы защищенного FTPS-соединения.



**Блок `"webdavd"` (Настройки службы WebDAV):**

* 
`bindings`: Настройки порта (значение `0` отключает службу), сертификатов HTTPS и правил обработки прокси-заголовков для WebDAV.


* 
`cors`: Конфигурация Cross-Origin Resource Sharing для управления доступом к файлам через WebDAV напрямую из браузерных приложений.


* 
`cache`: Настройки внутреннего кэширования для ускорения работы с пользователями и MIME-типами.



**Блок `"data_provider"` (Хранилище данных и настроек):**

* `driver`: Задает тип используемой базы данных; в данном конфиге выбран драйвер `sqlite`.


* 
`name`: Путь к файлу базы данных, если используется SQLite (здесь `/var/lib/sftpgo/sftpgo.db`).


* 
`users_base_dir`: Глобальная директория на сервере ( `/srv/sftpgo/data`), внутри которой по умолчанию создаются папки пользователей.


* 
`actions` и `hooks`: Настройки внешних скриптов для валидации или перехвата событий авторизации пользователей.


* 
`password_hashing`: Конфигурация алгоритмов хеширования (например, `bcrypt` и `argon2`) для безопасного хранения паролей в базе.


* 
`create_default_admin`: Флаг, указывающий, нужно ли автоматически создавать учетную запись администратора при инициализации базы.


* 
`backups_path`: Папка, в которую сервер будет сохранять резервные копии своих настроек (`/srv/sftpgo/backups`).



**Блок `"httpd"` (Веб-интерфейс и REST API):**

* 
`bindings`: Настройка HTTP-сервера, прослушивающего порт `8080`, с включенными панелью администратора (`enable_web_admin`), веб-клиентом (`enable_web_client`) и API (`enable_rest_api`).


* 
`oidc`: Блок настроек OpenID Connect для интеграции внешнего провайдера авторизации (SSO), включающий параметры `client_id`, `scopes` (например, `openid`, `profile`) и URL-адреса перенаправления.


* 
`security`: Настройки безопасности HTTP-ответов, включая заголовки CSP, HSTS и правила редиректа.


* 
`branding`: Раздел для кастомизации визуального оформления интерфейса, где можно указать пути к собственным логотипам, фавиконкам и CSS-стилям.


* 
`templates_path`, `static_files_path`: Директории, из которых веб-сервер загружает HTML-шаблоны и статические ресурсы.



**Остальные служебные блоки:**

* 
`telemetry`: Параметры для запуска эндпоинта метрик формата Prometheus и профилировщика нагрузки.


* 
`http`: Настройки таймаутов, ожидания и сертификатов для встроенного HTTP-клиента, с помощью которого SFTPGo делает исходящие запросы.


* 
`command`: Глобальные таймауты и переменные окружения для выполнения сервером любых внешних системных команд.


* 
`kms`: Параметры Key Management Service, используемые для безопасного шифрования конфиденциальных данных и секретов в базе данных.


* 
`mfa`: Настройки многофакторной аутентификации, в частности конфигурация генерации TOTP-токенов (название приложения в аутентификаторе и алгоритм `sha1`).


* 
`smtp`: Учетные данные и настройки почтового сервера (порт `587`, поддержка OAuth2) для отправки сервером системных email-уведомлений.


* 
`plugins`: Массив для подключения и конфигурации внешних бинарных плагинов, расширяющих базовый функционал SFTPGo.
