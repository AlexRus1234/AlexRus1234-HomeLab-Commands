
### Как пользоваться:

1.  Подключитесь к чистому серверу: `ssh root@IP`.
2. На домашнем ПК создайте ключ (если его нет ещё)  `ssh-keygen -t ed25519 -f <имя>`
3.  (Если ключа еще нет) Выйдите и отправьте ключ: `type <имя>.pub | ssh root@<ip> "cat >> ~/.ssh/authorized_keys"`.
4.  Создайте скрипт:
    ```bash
    nano setup.sh
    ```
    *(Вставьте код, Ctrl+O, Enter, Ctrl+X)*
5.  Дайте права:
    ```bash
    chmod +x setup.sh
    ```
6.  Запустите:
    ```bash
    ./setup.sh
    ```
    *(Вас спросят имя пользователя и пароль — вставьте их из вашего менеджера паролей)*.

Скрипт в конце выдаст зеленый отчет с новым рандомным портом и подтверждением, что все системы (CrowdSec, Endlessh, Swap) активны.
