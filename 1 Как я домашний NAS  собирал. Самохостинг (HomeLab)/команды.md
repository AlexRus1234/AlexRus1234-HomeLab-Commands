# Создание отказоустойчивого NAS: Arch Linux, ZFS и Btrfs
---

## Этап 1. Базовая настройка системы и оптимизация зеркал

Для быстрой загрузки пакетов необходимо выбрать актуальные зеркала репозиториев Arch Linux.

1. Установите утилиту автоматического поиска зеркал:
   ```bash
   sudo pacman -S reflector
   ```
2. Откройте файл конфигурации:
   ```bash
   sudo nano /etc/xdg/reflector/reflector.conf
   ```
3. Приведите файл к следующему виду (удалите лишнее и добавьте нужные страны):
   ```ini
   --save /etc/pacman.d/mirrorlist
   --protocol https
   --age 24
   --number 20
   --sort rate
   --country Russia,Germany,Netherlands,Finland,France
   ```
4. Создайте директорию для таймера и файл переопределения:
   ```bash
   sudo mkdir -p /etc/systemd/system/reflector.timer.d
   sudo nano /etc/systemd/system/reflector.timer.d/override.conf
   ```
5. Вставьте следующий блок для ежедневного запуска:
   ```ini
   [Timer]
   OnCalendar=
   OnCalendar=daily
   RandomizedDelaySec=12h
   ```
6. Примените настройки и запустите службу:
   ```bash
   sudo systemctl daemon-reload
   sudo systemctl enable --now reflector.timer
   sudo systemctl start reflector.service
   sudo pacman -Syy
   ```

*Система использует наиболее быстрые серверы для загрузки обновлений.*

## Этап 2. Создание программного массива Btrfs (Root) и настройка загрузчика

Для обеспечения отказоустойчивости операционной системы системный раздел дублируется на второй NVMe-накопитель (создается RAID1).

1. Установите необходимые пакеты для работы с дисками и файловыми системами:
   ```bash
   sudo pacman -Syu gptfdisk btrfs-progs snapper grub-btrfs inotify-tools base-devel linux-firmware dosfstools parted
   ```
2. Подготовьте разделы на первом диске (`/dev/nvme1n1`). Создайте раздел для торрентов (340 GiB) и раздел для метаданных ZFS (350 GiB):
   ```bash
   sudo sgdisk -n 3:0:+340G -t 3:8300 -c 3:"torent" /dev/nvme1n1
   sudo sgdisk -n 4:0:+350G -t 4:BF00 -c 4:"metaZFS" /dev/nvme1n1
   ```
3. Скопируйте таблицу разделов на второй диск (`/dev/nvme0n1`) и сгенерируйте новые уникальные идентификаторы (UUID):
   ```bash
   sudo sgdisk -R /dev/nvme0n1 /dev/nvme1n1
   sudo sgdisk -G /dev/nvme0n1
   ```
4. Добавьте системный раздел второго диска в корневую файловую систему и запустите балансировку `[конвертацию]` в RAID1:
   ```bash
   sudo btrfs device add -f /dev/nvme0n1p2 /
   sudo btrfs balance start -dconvert=raid1 -mconvert=raid1 /
   ```
5. Подготовьте загрузочный раздел на втором диске и продублируйте загрузчик GRUB:
   ```bash
   sudo mkfs.fat -F32 /dev/nvme0n1p1
   sudo grub-install --target=x86_64-efi --efi-directory=/boot --bootloader-id=GRUB /dev/nvme1n1
   sudo mkdir -p /mnt/efi-second
   sudo mount /dev/nvme0n1p1 /mnt/efi-second
   sudo grub-install --target=x86_64-efi --efi-directory=/mnt/efi-second --bootloader-id=GRUB /dev/nvme0n1
   sudo umount /mnt/efi-second
   sudo rmdir /mnt/efi-second
   ```

*Теперь при выходе из строя одного NVMe-накопителя система продолжит работу.*

## Этап 3. Настройка кэш-диска для торрентов (Btrfs RAID0)

Раздел для временных файлов скачивания объединяется в RAID0 для увеличения скорости и объема.

1. Обновите информацию о разделах в ядре:
   ```bash
   sudo partprobe
   ```
2. Создайте массив RAID0 (данные) с зеркалированием метаданных (RAID1):
   ```bash
   sudo mkfs.btrfs -d raid0 -m raid1 -f -L torent /dev/nvme1n1p3 /dev/nvme0n1p3
   ```
3. Узнайте UUID созданного раздела:
   ```bash
   lsblk -f | grep torent
   ```
4. Откройте файл `/etc/fstab` и добавьте строку для автоматического монтирования (замените UUID на свой):
   ```bash
   sudo nano /etc/fstab
   ```
   ```ini
   UUID=ВАШ_UUID /mnt/torent  btrfs  defaults,noatime  0  0
   ```
5. Смонтируйте раздел, создайте подтом `[subvolume]` и отключите функцию Copy-on-Write `[копирование при записи]` во избежание износа диска и фрагментации:
   ```bash
   sudo mkdir -p /mnt/torent
   sudo mount /mnt/torent
   sudo btrfs subvolume create /mnt/torent/downloads
   sudo chattr +C /mnt/torent/downloads
   ```
6. Убедитесь, что атрибут применен (в выводе должна быть буква `C`):
   ```bash
   lsattr -d /mnt/torent/downloads
   ```

## Этап 4. Настройка автоматических снимков системы (Snapper)

1. Создайте базовую конфигурацию для корневого раздела:
   ```bash
   sudo snapper -c root create-config /
   ```
2. Настройте права доступа к директории снимков:
   ```bash
   sudo chmod 750 /.snapshots
   ```
3. Активируйте системные таймеры для создания снимков и интеграцию с загрузчиком GRUB:
   ```bash
   sudo systemctl enable --now snapper-timeline.timer
   sudo systemctl enable --now snapper-cleanup.timer
   sudo systemctl enable --now grub-btrfs.path
   ```
4. Создайте первый снимок вручную и обновите конфигурацию загрузчика:
   ```bash
   sudo snapper -c root create -d "System Ready"
   sudo grub-mkconfig -o /boot/grub/grub.cfg
   ```
5. **ВАЖНО:** Выполните перезагрузку системы для применения всех параметров.

## Этап 5. Установка файловой системы ZFS

Поскольку ZFS не включена в стандартное ядро Linux из-за лицензионных ограничений, установка производится из стороннего репозитория.

1. Импортируйте и подпишите ключи разработчиков:
   ```bash
   sudo pacman-key --recv-keys F75D9D76
   sudo pacman-key --lsign-key F75D9D76
   ```
2. Откройте конфигурацию пакетного менеджера:
   ```bash
   sudo nano /etc/pacman.conf
   ```
3. В конец файла добавьте репозиторий:
   ```ini
   [archzfs]
   Server = https://archzfs.com/$repo/x86_64
   ```
4. Установите заголовки ядра и модуль ZFS (процесс компиляции займет несколько минут):
   ```bash
   sudo pacman -Syu linux-lts-headers zfs-dkms
   ```
5. Проверьте успешность установки модуля:
   ```bash
   sudo modprobe zfs
   ```

## Этап 6. Создание массива данных (ZFS Pool)

**ВАЖНО:** При создании пула ZFS необходимо использовать идентификаторы дисков (ID), а не стандартные имена `/dev/sda`, так как они могут меняться при перезагрузке.

1. Выведите список идентификаторов жестких дисков:
   ```bash
   ls -l /dev/disk/by-id/ | grep -v part | grep ata
   ```
   *(Скопируйте ID ваших шести жестких дисков для следующей команды).*
2. Создайте пул с именем `tank` (RAIDZ2) и специальным зеркалом из NVMe (`special mirror`) для метаданных:
   ```bash
   sudo zpool create -f -o ashift=12 \
    -O compression=zstd \
    -O xattr=sa \
    -O acltype=posixacl \
    -O atime=off \
    -O special_small_blocks=64K \
    tank \
    raidz2 \
      /dev/disk/by-id/ВАШ_DISK1_ID \
      /dev/disk/by-id/ВАШ_DISK2_ID \
      /dev/disk/by-id/ВАШ_DISK3_ID \
      /dev/disk/by-id/ВАШ_DISK4_ID \
      /dev/disk/by-id/ВАШ_DISK5_ID \
      /dev/disk/by-id/ВАШ_DISK6_ID \
    special mirror \
      /dev/nvme1n1p4 \
      /dev/nvme0n1p4
   ```
3. Сгенерируйте файл кэша и включите службы автомонтирования:
   ```bash
   sudo zpool set cachefile=/etc/zfs/zpool.cache tank
   sudo systemctl enable zfs-import-cache
   sudo systemctl enable zfs-mount
   sudo systemctl enable zfs.target
   ```
4. Создайте логический раздел `[dataset]` для хранения файлов:
   ```bash
   sudo zfs create tank/data
   ```
5. Передайте права на директорию вашему системному пользователю (замените `ВАШ_ПОЛЬЗОВАТЕЛЬ` на свой логин):
   ```bash
   sudo chown -R ВАШ_ПОЛЬЗОВАТЕЛЬ:ВАШ_ПОЛЬЗОВАТЕЛЬ /tank/data
   ```
6. **Настройка службы принудительного импорта.** Для предотвращения ошибок при загрузке создайте дополнительную службу:
   ```bash
   sudo nano /etc/systemd/system/zfs-force-import.service
   ```
   ```ini
   [Unit]
   Description=Force Import ZFS Pool Tank
   After=modprobe@zfs.service
   Requires=modprobe@zfs.service
   After=network.target

   [Service]
   Type=simple
   Restart=on-failure
   RestartSec=5s
   TimeoutStartSec=180
   ExecStart=/bin/sh -c '/usr/bin/zpool list tank >/dev/null 2>&1 || /usr/bin/zpool import -f -d /dev/disk/by-id tank'
   ExecStartPost=/usr/bin/zfs mount -a

   [Install]
   WantedBy=multi-user.target
   ```
7. Активируйте службу:
   ```bash
   sudo systemctl daemon-reload
   sudo systemctl enable zfs-force-import.service
   ```

## Этап 7. Настройка файлового сервера (Samba)

1. Установите службы файлового доступа и сетевого обнаружения:
   ```bash
   sudo pacman -S samba wsdd avahi
   ```
2. Создайте пароль для доступа к сетевой папке (введите свой системный логин):
   ```bash
   sudo smbpasswd -a ВАШ_ПОЛЬЗОВАТЕЛЬ
   ```
3. Отредактируйте конфигурационный файл Samba:
   ```bash
   sudo nano /etc/samba/smb.conf
   ```
   Вставьте следующую конфигурацию (замените логин в строке `valid users`):
   ```ini
   [global]
   workgroup = WORKGROUP
   server string = SKLD00 File Server
   netbios name = SKLD00
   security = user
   map to guest = Bad User
   log file = /var/log/samba/%m.log
   max log size = 50
   logging = systemd
   server min protocol = SMB2
   
   vfs objects = catia fruit streams_xattr
   fruit:metadata = stream
   fruit:model = MacSamba
   fruit:posix_rename = yes
   fruit:veto_appledouble = no
   fruit:nfs_aces = no
   fruit:wipe_intentionally_left_blank_rfork = yes
   fruit:delete_empty_adfiles = yes

   [Share]
   path = /tank/data
   read only = no
   browsable = yes
   valid users = ВАШ_ПОЛЬЗОВАТЕЛЬ
   create mask = 0664
   directory mask = 0775
   ```
4. Настройте обнаружение устройства в сетях Linux/macOS (Avahi):
   ```bash
   sudo nano /etc/avahi/services/samba.service
   ```
   ```xml
   <?xml version="1.0" standalone='no'?>
   <!DOCTYPE service-group SYSTEM "avahi-service.dtd">
   <service-group>
    <name replace-wildcards="yes">%h</name>
    <service>
      <type>_smb._tcp</type>
      <port>445</port>
    </service>
    <service>
      <type>_device-info._tcp</type>
      <port>0</port>
      <txt-record>model=RackMac</txt-record>
    </service>
   </service-group>
   ```
5. **Создание службы "Kickstart".** Для гарантированного запуска сетевых сервисов после монтирования дисков создайте отложенную службу:
   ```bash
   sudo systemctl disable smb nmb wsdd avahi-daemon
   sudo nano /etc/systemd/system/nas-kickstart.service
   ```
   ```ini
   [Unit]
   Description=Force start Samba and WSDD after boot
   After=multi-user.target

   [Service]
   Type=oneshot
   ExecStart=/bin/bash -c "sleep 20; systemctl start smb nmb wsdd avahi-daemon"

   [Install]
   WantedBy=multi-user.target
   ```
6. Активируйте службу:
   ```bash
   sudo systemctl enable nas-kickstart.service
   ```

## Этап 8. Настройка службы скачивания файлов (qBittorrent)

1. Установите консольную версию клиента:
   ```bash
   sudo pacman -S qbittorrent-nox
   ```
2. Подготовьте директории для загрузок и выдайте права:
   ```bash
   mkdir -p /mnt/torent/temp
   mkdir -p /tank/data/downloads
   sudo chown -R ВАШ_ПОЛЬЗОВАТЕЛЬ:ВАШ_ПОЛЬЗОВАТЕЛЬ /mnt/torent
   sudo chown -R ВАШ_ПОЛЬЗОВАТЕЛЬ:ВАШ_ПОЛЬЗОВАТЕЛЬ /tank/data/downloads
   ```
3. Создайте системную службу для работы клиента в фоновом режиме:
   ```bash
   sudo nano /etc/systemd/system/qbittorrent.service
   ```
   Вставьте конфигурацию (замените `ВАШ_ПОЛЬЗОВАТЕЛЬ` на ваш логин):
   ```ini
   [Unit]
   Description=qBittorrent Command Line Client
   After=network.target

   [Service]
   User=ВАШ_ПОЛЬЗОВАТЕЛЬ
   Group=ВАШ_ПОЛЬЗОВАТЕЛЬ
   Type=simple
   ExecStart=/usr/bin/qbittorrent-nox
   Restart=on-failure

   [Install]
   WantedBy=multi-user.target
   ```
4. Активируйте и запустите службу:
   ```bash
   sudo systemctl enable --now qbittorrent
   ```
5. Получите сгенерированный временный пароль для входа в веб-интерфейс:
   ```bash
   journalctl -u qbittorrent -n 20 --no-pager
   ```
   *(Найдите строку: "The temporary password is: ...").*
6. На основном компьютере откройте браузер и введите `http://IP_АДРЕС_NAS:8080`.
   * **Логин:** admin
   * **Пароль:** скопированный временный пароль.
7. В веб-интерфейсе перейдите в **Settings** (Шестеренка):
   * В разделе **Web UI** измените логин и задайте новый постоянный пароль.
   * В разделе **Downloads** укажите пути:
     * **Default Save Path:** `/tank/data/downloads/`
     * Отметьте **Keep incomplete torrents in:** `/mnt/torent/temp/`
8. Нажмите **Save**.

*Конфигурация сервера хранения данных завершена.*
